# Security Policy

## Reporting a vulnerability

Please do **not** open a public issue for security problems.

Instead, use [GitHub private vulnerability reporting](../../security/advisories/new)
("Report a vulnerability" under the repository's **Security** tab). Reports go
directly to the maintainers and stay private while we investigate.

Include what you found, a minimal reproduction, and the affected package
(`python/`, `rooms/`, or `templates/`). We aim to acknowledge reports within
a few business days.

## Supported versions

The SDK is in alpha; only the latest commit on `main` receives fixes.
