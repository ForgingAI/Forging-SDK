# forging-sdk (Python)

Plugin and module SDK for the Forging platform. See the
[repository root README](../README.md) for the full SDK overview
and the `rooms/` package for the TypeScript multiplayer client.

## Install

```bash
pip install -e .
# or, with uv:
uv sync --all-extras
```

## CLI

The `forging` console script is the primary entry point:

```bash
forging --help
```

See `src/forging_sdk/` for the package layout.
